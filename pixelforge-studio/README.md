# PixelForge Studio

A responsive portfolio for a personal web studio, built with semantic HTML, modern CSS, and vanilla JavaScript.

## Project files

- `index.html` — Portfolio content, project links, and semantic structure.
- `styles.css` — Design tokens, layout, responsive rules, and visual styling.
- `main.js` — Responsive navigation and Formspree contact-form submission.
- `assets/images/` — Reserved for real project imagery.
- `assets/icons/` — Reserved for additional icon assets.

## Preview

Open `index.html` in a browser. No build step or external dependencies are required.

The project cards link to published practical projects. To enable contact-form submissions, paste the endpoint from your Formspree form into `FORM_ENDPOINT` in `main.js`. It is empty by default, so the form does not send requests until configured.
